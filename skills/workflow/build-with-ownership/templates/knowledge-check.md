# Knowledge Check

The engineer should explain these without reading Claude's summary first.

## Reconstruction

1. Trace one request or event from entry to completion.
2. Name the source of truth and every secondary representation.
3. State the transaction boundary.
4. List the important invariants and where each is enforced.
5. Explain duplicate, retry, ordering, and concurrency behavior.
6. Describe the most likely partial failure.
7. Explain how logs, metrics, traces, or database state reveal it.
8. Explain recovery and rollback.
9. Identify one abstraction or library whose hidden behavior matters.
10. Identify one thing the automated tests do not prove.

## Quiz behavior

Ask one question at a time. Wait for the engineer's answer. Challenge vague answers. Request exact files, functions, constraints, queries, or tests. Reveal the answer only after the engineer responds.
